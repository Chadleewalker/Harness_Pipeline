# Known Issues

- [ ] 1. [2026-07-11] yolo_docker: Docker commands must run from Git Bash, not WSL — the WSL distro has no Docker Desktop integration ("docker-compose could not be found in this WSL 2 distro"). Start-Agent.bat hard-codes Git Bash (C:\Program Files\Git\bin\bash.exe) for this reason; never use a bare PATH lookup for bash.exe (it resolves to the WSL launcher).
- [ ] 2. [2026-07-11] yolo_docker: the code-server editor terminal does NOT inherit docker-compose `environment:` vars (s6 cleans the env) and runs as non-root user abc (uid 911). Anything the terminal needs (e.g. CLAUDE_CODE_OAUTH_TOKEN) must be written by entrypoint.sh to /etc/profile.d/*.sh with 644 perms (600 is unreadable to abc). `docker exec` inherits container env and gives FALSE test positives — test as abc inside the chroot.
- [ ] 3. [2026-07-11] yolo_docker: interactive `claude` ignores CLAUDE_CODE_OAUTH_TOKEN at first-run onboarding and demands browser OAuth sign-in (headless `claude -p` works fine). Fix baked into entrypoint.sh: set "hasCompletedOnboarding": true in /config/.claude.json (jq is in the image; python3/node are not).
